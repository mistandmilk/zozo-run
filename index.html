Look Around Quest

Spell the word to escape the zombie!

For grown-ups: a spooky-cartoon runner that teaches three-letter (CVC) spelling with phonic sounds. It is intense for ages 3 to 5, so play the first levels together. Zozo can never end the game: if he catches the runner he roars, then the run restarts from the same spot. The built-in voice varies by device, so for best results recorded phonic clips can replace it later.
